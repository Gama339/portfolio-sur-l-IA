1️⃣ L’IA générative comme assistant de développement web (front-end & back-end)
📌 Sujet

Les IA génératives de code (comme ChatGPT, GitHub Copilot ou CodeWhisperer) sont utilisées comme assistants intelligents pour accélérer le développement web.
Elles aident à :

Générer du code HTML, CSS, JavaScript, React, Vue, etc.

Créer des API back-end (Node.js, Python, PHP…)

Corriger des bugs et expliquer du code existant

Améliorer la productivité des développeurs

🎯 Enjeu

Réduction du temps de développement, mais dépendance accrue aux outils automatisés et nécessité de garder un esprit critique sur la qualité et la sécurité du code généré.

🔗 Sources

GitHub – About GitHub Copilot
https://docs.github.com/en/copilot

OpenAI – Introducing ChatGPT
https://openai.com/blog/chatgpt

Mozilla Developer Network (MDN) – AI-assisted coding overview
https://developer.mozilla.org/
